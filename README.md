# ![](https://user-images.githubusercontent.com/4441470/224455560-91ed3ee7-f510-4041-a8d2-3fc093025112.png) Soenneker.Cloudflare.NuGet
### A private NuGet service on Cloudflare Workers, Containers, D1, and R2.

## Installation

```
dotnet add package Soenneker.Cloudflare.NuGet
```

The file is copied to the output directory, and located at the relative path: `Resources\`.
